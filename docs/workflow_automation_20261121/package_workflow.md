# Bounded package-backed workflow command

This is a usable entry to the package-backed workflow slice, NOT universal company research or an untouched upstream agent. It composes existing registry acquisition, historical source gate, model lead, adapted DIALECTIC committee, optional Ragas argument-support review, research-gap feedback and conditional final acceptance. ODR historical-website navigation remains a separate optional provider, not used by this command.

## Run

From the existing project checkout on E: (not the read-only ChatGPT sources mirror):

```powershell
$env:PYTHONPATH='src'
python -m closed_loop.package_workflow --config docs/workflow_automation_20261121/package_workflow_example.json --output-dir results/scratch/package_workflow_my_unique_run --approve-cli
```

The output directory must be new. Do not rerun a sealed experiment just by choosing another directory: a different path is not authorization to repeat it. The example is a starting config, not a new scheduled run or instruction to execute it automatically.

`--approve-cli` explicitly enables existing local Claude Code CLI use. Local claude.ai login must already work; direct API/environment routing is rejected. No new API key or subscription is created. CLI checks auth separately (20s timeout) before the collection/analysis deadline starts. Model-process caps do not establish an exact internal inference count or dollar invoice. Quota/transport failures are recorded, not retried or rerouted.

## Scope and limits

- Strict identity seed and mandate; cutoff is locked to this project’s2024-04-04T23:59:59Z (UTC-equivalent offsets accepted). Extra Y/outcome fields rejected.
- Package format wheel/npm; collector handles supported unscoped names and canonical lowercase unencoded @scope/name for npm (PyPI unchanged). Scope is retained in identity checks and download paths; it is not corporate ownership proof. At most2registry HTTP attempts,24model process attempts,480s for collection/analysis,2research passes,concurrency1.
- Collector and model stages share the same budget; source gate runs before backend construction.
- Only embedded historical documentation is model evidence. Current registry descriptions/latest README fields are excluded. Package bytes are stored for reproducibility, never installed/executed.
- The finite package provider cannot follow arbitrary current links or discover every missing business fact. No new evidence yields MORE_DILIGENCE, not PASS.
- Support checker is an automatic diagnostic, not independent verification, investment accuracy or human approval. Missing support becomes a question; it does not prove the claim false.
- Recognized placeholder argument outputs stop before evaluator/research feedback. Other semantic defects can remain.

No output is overwritten and no automatic resume/retry is implemented here.
